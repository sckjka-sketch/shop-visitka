# SMM: ведение соцсетей магазина

Здесь работает агент `smm-manager` для Claude Code (определение — в `.claude/agents/smm-manager.md`).
Он готовит контент-планы, посты для Telegram, ВКонтакте и Instagram, сценарии сторис и Reels, ответы на комментарии.
Сам агент ничего не публикует: он сохраняет черновики, а вы проверяете и публикуете.

## Как начать

1. Заполните бриф `smm/brand.md` — это единственный источник фактов о магазине для агента.
2. Откройте Claude Code в этом репозитории и попросите, например:
   - «Используй smm-manager: составь контент-план на октябрь для Telegram и ВК»
   - «smm-manager, напиши пост о новинке — <описание> — для всех площадок»
   - «smm-manager, ответь на отзыв: <текст отзыва>»
   - «smm-manager, придумай сценарий Reels на 15 секунд про упаковку заказа»
3. Проверьте места с пометкой `[УТОЧНИТЬ: ...]` — там агенту не хватило данных.
4. Опубликуйте пост и поменяйте в файле `Статус: черновик` на `опубликовано`.

## Структура

```
smm/
├── brand.md   — бриф бренда (заполняете вы)
├── plans/     — контент-планы
└── posts/     — черновики и опубликованные посты
```
