# Бриф бренда для SMM

Этот файл читает агент `smm-manager` перед каждой задачей. Заполните поля вместо `<...>`.
Чем подробнее бриф, тем точнее посты. Всё, чего здесь нет, агент не будет выдумывать, а пометит как `[УТОЧНИТЬ]`.
